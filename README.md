# INTS 위험성평가

(주)아이엔티에스 위험성평가 실시·기록 앱. `index.html` 하나로 동작 (GitHub Pages).

- 2025 사후점검 지적사항 개선 관리 (증빙 사진)
- 위험성평가표 (빈도 5 × 강도 4, 공정 분류, 감소대책·개선 전후 사진, 삭제 이력)
- TBM 일지 (작업장별, 평가표 위험요인 체크, 참석자 손서명)
- 교육·회의 결과 보고서, 수시평가 기록, 중량물 취급 작업계획서
- 실시계획서 문서 화면에서 바로 편집 · A4 인쇄
- 다음 연도로 복사, JSON 백업

데이터: Firebase `ints-weekly` 프로젝트 Firestore `ra_*` 컬렉션. 서버 연결 실패 시 브라우저 저장(⚠ 표시).
`?local` 을 붙이면 브라우저 저장 모드로 강제 (테스트용).
